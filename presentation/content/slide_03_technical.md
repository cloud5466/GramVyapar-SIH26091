# Slide 3 — Technical Approach / Data / Architecture

## PURPOSE

Show how the system separates evidence, deterministic decisions and AI
explanation.

## MAIN MESSAGE

Data provides the evidence. Code performs critical calculations. AI explains
the decision.

## VISUAL

User Input → Data & Evidence → Normalization → Decision Engines → Advisory
Engine → Simple Result + Detailed Analysis.

## CONTENT

- Evidence inputs: population, mapped competitors, MSME context, business
  profiles and entrepreneur-provided local inputs.
- Decision engines: local data, viability and financial rules.
- AI is constrained by calculated and sourced evidence.
- Each output can carry evidence type, confidence and source references.

## DATA REQUIRED

Final data-source inventory, normalized schemas and sample engine response
contract.

## SOURCE REQUIRED

`docs/ARCHITECTURE.md`, `docs/DATA_CONTRACT.md`,
`docs/SOURCE_POLICY.md` and verified data-source records.
