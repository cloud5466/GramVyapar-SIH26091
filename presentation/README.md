# Presentation workspace

Owner: **Member 5 — Presentation / UX Lead**

This workspace stores source-backed content for the planned six-slide Smart
India Hackathon presentation. It does not contain the final PPT.

- `content/`: one structured markdown brief per slide.
- `screenshots/`: approved product screenshots with capture notes.
- `diagrams/`: editable or exported architecture and journey diagrams.

Every quantitative or factual claim must be registered in
`testing/claim_audit.md`. Illustrative prototype values must be labelled
clearly on the slide and in its content file.
