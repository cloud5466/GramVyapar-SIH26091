# Demo checklist

Owner: **Member 6 — QA / Demo / Jury Lead**

## Before Demo

- [ ] Confirm the deployed URL and local fallback both open
- [ ] Confirm team, institution and problem-statement identity
- [ ] Run lint, build and the approved regression checks
- [ ] Verify every displayed claim in `claim_audit.md`
- [ ] Confirm illustrative values are labelled
- [ ] Charge devices and disable disruptive notifications

## Golden Demo Case

- [ ] Use one approved location from the two-location MVP scope
- [ ] Use one supported business category
- [ ] Use reviewed input values
- [ ] Confirm expected deterministic outputs before presenting
- [ ] Prepare a one-minute and a three-minute walkthrough

## Backup

- [ ] Save approved screenshots in `presentation/screenshots/`
- [ ] Keep an offline/local build available
- [ ] Prepare a short architecture walkthrough without live interaction
- [ ] Keep source and calculation evidence easy to open

## Internet Failure

- [ ] Switch to the local build
- [ ] Explain which future data calls require connectivity
- [ ] Use approved screenshots if a local dependency is unavailable

## AI Failure

- [ ] Demonstrate deterministic calculations independently
- [ ] Show the expected advisory output from an approved captured example
- [ ] Explain that AI is the explanation layer, not the critical calculator

## Presentation Day

- [ ] Complete final smoke test on the presentation device
- [ ] Confirm projector readability and mobile responsiveness
- [ ] Assign the primary speaker and backup operator
- [ ] Keep jury answers and source register open
- [ ] Freeze code and content before the scheduled presentation
